# BLOCKVERSE Android APK project

This is a simple Android WebView wrapper for the BLOCKVERSE puzzle game.

## Build APK using GitHub (no Android Studio)
1. Extract this ZIP on your computer.
2. Open your GitHub repository `magi999567/BLOCKVERSE`.
3. Upload the **contents** of this folder to the repository root. Keep the `.github` folder.
4. Commit the files to `main` (or `master`).
5. Open the repository's **Actions** tab and select **Build BLOCKVERSE APK** if it did not start automatically.
6. Open the completed workflow run and download the `BLOCKVERSE-debug-APK` artifact.
7. Extract the artifact ZIP; install `app-debug.apk` on your Android phone.

This is a debug APK for testing. A signed release build is needed for Google Play publication.
